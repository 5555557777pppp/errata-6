# errata-6
定義1.43(2)(p.25): 「f(x_α − x) → 0」は f(x_α − x₀) → 0 のはずです。直後で「x_α は x₀ に弱収束」と言っているので、x は x₀ の誤りです。
演習問題1.18(p.28): 「|ξ| ≤ 1/n」は |ξ_n| ≤ 1/n のはずです。添字 n が抜けています
補題2.25の証明の最終行(p.41): 「Σ_{n=0}^∞ |c_nζⁿ| ≤ Σ_{n=1}^∞ |c_n| ≤ 2」の中央の和は Σ_{n=0}^∞ |c_n| のはずです。直前の「Σ_{n=0}^N |c_n| ≤ 2」とも合いません。
定理2.42(2)の証明(p.53): 「‖(I+T*R)⁻¹y‖ ≤ ‖y‖」の T*R は T*T のはずです。R は他に出てきません。
例2.45(p.55): 絶対連続の特徴づけ「f(t)=f(0)+∫₀ᵗ g(s)ds (0≤s≤1)」の範囲は 0≤t≤1 のはずです(s は積分変数です)。
演習2.17のヒント(p.60): 「𝓕P₀𝓕 = −Q₀」は、右の 𝓕 が 𝓕⁻¹(= 𝓕*)のはずです
記号の不統一(p.73 vs p.74〜76)
定理3.28では「σ(A)を含む開集合 G_f」とありますが、証明(p.75)と3.28(3)(p.76)では D_f になっています。
