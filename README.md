明確な誤り(誤植・記号ミス)

	•	p.251 (A.3): 2次の項が f′(x₀) になっています。正しくは f″(x₀) です。
	•	p.234 (12.59): I_x と I_y の被積分関数が逆です。x軸まわりの I_x は ∫σy²dS、y軸まわりの I_y は ∫σx²dS のはずです。I_z = I_x + I_y という結論には影響しません。
	•	p.255 (A.29) 直後: 「2番目の等号で(A.29)を用い」は自己参照です。正しくは (A.28) です。
	•	p.253 脚注2: 「x₂/x₁ ≠ 0」とありますが、正しくは「≠ 定数」です。x₂ = 2x₁ は比が0でなくても従属です。
	•	p.253〜254: 「(A.17)の一般解」「(A.17)の斉次方程式」とありますが、(A.17) は特性方程式で、斉次方程式は (A.16) です。
