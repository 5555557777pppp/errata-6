誤植・計算ミス等の報告一覧

1. p.200 式 (11.40),(11.41)
    x_1,x_2 の右辺が入れ替わっているようです。
    正しくは
    x_1=\frac{2\widetilde X-\widetilde x+2a}{2},
    \qquad
    x_2=\frac{2\widetilde X+\widetilde x+4a}{2}.
    現行の (11.40) は本来 x_2 の式、(11.41) は本来 x_1 の式と思われます。
2. p.222 式 (12.6) 中辺
    r\rho(r_i)\Delta V_i
    の r は r_i の誤植と思われます。
    正しくは
    r_i\rho(r_i)\Delta V_i.
3. p.224 式 (12.18) 3行目
    \Delta V は \Delta V_i の誤植と思われます。
4. p.232 Exercise 12.3 T_2
    v_2=-v より dv_2/dt=-dv/dt となるため、T_2 の式に符号・係数の誤りがあるようです。正しくは
    T_2
    =m_2g\left\{
    1+\frac{(m_1-m_2)a^2}
    {I+(m_1+m_2)a^2}
    \right\}.
    D=I+(m_1+m_2)a^2 とおけば、
    T_1=\frac{m_1g(I+2m_2a^2)}{D},
    \qquad
    T_2=\frac{m_2g(I+2m_1a^2)}{D}.
    特に I=0 の場合、
    T_1=T_2=\frac{2m_1m_2g}{m_1+m_2}
    となるため、現行の T_2 の式とは一致しません。
5. p.251 式 (A.3)

6. p.253 脚注2
    「x_2/x_1\ne0」は線形独立性の条件として不適切と思われます。
    「x_2/x_1\ne 定数」等が適切です。例えば x_2=2x_1 の場合、x_2/x_1=2\ne0 ですが、x_1,x_2 は従属です。
7. p.253～254

    (A.17) は特性方程式であり、対象となる斉次微分方程式は (A.16) です。

    ここは「2番目の等号で (A.28) を用い」が正しいと思われます。
