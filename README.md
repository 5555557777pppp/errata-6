1. p.200 式 (11.40),(11.41)
    x_1,x_2 の右辺が入れ替わっているようです。
    正しくは
    x_1=\frac{2\widetilde X-\widetilde x+2a}{2},\qquad
    x_2=\frac{2\widetilde X+\widetilde x+4a}{2}.
2. p.232 Exercise 12.3 T_2
    v_2=-v より dv_2/dt=-dv/dt となるため、T_2 の式に符号（係数）の誤りがあるようです。正しくは
    T_2=m_2g\left\{1+
    \frac{(m_1-m_2)a^2}
    {I+(m_1+m_2)a^2}\right\}.
    D=I+(m_1+m_2)a^2 とすると
    T_1=\frac{m_1g(I+2m_2a^2)}D,\qquad
    T_2=\frac{m_2g(I+2m_1a^2)}D.
    I=0 では T_1=T_2=2m_1m_2g/(m_1+m_2) となります。
3. p.251 式 (A.3)

4. p.253 脚注2

5. p.253～254
